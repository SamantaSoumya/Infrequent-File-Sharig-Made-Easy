How it works

01

Drop Your File

Select or drag any file — images, videos, documents, apps, ZIP archives — anything.

02

Get a Room ID

A unique Room ID + QR code is generated. Share either with your receiver.

03

Instant Transfer

WebRTC DataChannel streams bytes directly peer-to-peer. No server middleman.

Zero Server Storage

Your files never touch any server. They flow directly between browsers via an encrypted channel.

DTLS Encrypted

WebRTC DataChannel uses DTLS 1.2 encryption end-to-end. Even the signaling server can't read your data.

Full Network Speed

No server upload + download bottleneck. Direct P2P means you get the maximum speed your network allows.

Multi-File ZIP

Select multiple files and they'll be automatically zipped client-side before transfer. No file size limit imposed by us.

QR Code Sharing

Instantly share your Room ID via QR code — perfect for connecting your phone to your desktop.

No Sign-Up Required

Fully anonymous. No account, no email, no tracking. Open the page and start sharing immediately.
